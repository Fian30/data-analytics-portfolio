# SQL Database Design & Management

## Project Overview
This project focuses on designing and managing a relational database for an e-commerce case study using PostgreSQL and DBeaver.

## Tools
- PostgreSQL
- DBeaver
- SQL

## Project Objectives
- Design a relational database structure.
- Create tables with primary and foreign key relationships.
- Insert and manage data using SQL statements.
- Practice data manipulation and database modification.
- Retrieve data to validate the database structure and contents.

## Database Tables
The database includes the following tables:
- Categories
- Customers
- Products
- Orders
- Order Details

## SQL Operations
- `CREATE TABLE` — create database tables.
- `INSERT` — add records.
- `UPDATE` — modify existing records.
- `DELETE` — remove selected records.
- `ALTER TABLE` — modify table structures.
- `SELECT` — retrieve and validate data.

## Key Learnings
This project demonstrates fundamental relational database design, the use of primary and foreign keys, and common SQL operations for managing structured data.
